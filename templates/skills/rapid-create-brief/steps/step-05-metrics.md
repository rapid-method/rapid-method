# Step 5: Success Metrics

**Goal**: Define measurable success criteria split into **user success** (behavioral outcomes), **business objectives** (growth/revenue), and an **MVP success criteria** go/no-go gate.

**Previous step**: [step-04-scope.md](step-04-scope.md)
**Next step**: [step-06-acceptance.md](step-06-acceptance.md)

---

## 1. Open the Conversation

> "How will we know {project_name} is working? Let's start from the user side — what behavior would tell us they're getting real value?"

## 2. User Success Metrics

The key skill here: **push from vague to specific**. Always.

| Vague | Specific |
|-------|----------|
| "Users are happy" | "70% of users complete onboarding within 5 minutes" |
| "Product is useful" | "Active users return at least 2x per week and use core feature X" |
| "Good engagement" | "Median session time > 8 minutes; weekly retention > 40% at week 4" |
| "Users adopt it" | "30% of trial users convert to paid within 14 days" |

For each user success metric, capture:
- **Metric** — the behavioral outcome
- **Target** — concrete number or threshold
- **How to measure** — what tool, what definition

If the user struggles, suggest 3-4 candidate metrics for their product type and let them pick:
- **SaaS/web app**: activation rate, weekly retention, feature adoption
- **Marketplace**: liquidity, time-to-first-match, repeat usage
- **Tool**: time saved per task, completion rate, error rate
- **Content**: engagement depth, return frequency, share rate

## 3. Business Objectives

Separate from user metrics — what does the *business* need to see?

- **3 months**: {early signal target}
- **12 months**: {scale target}
- **Type**: revenue / growth / retention / cost savings / market position

For each:
- **Metric**, **Target**, **Timeframe**

If the user is unsure, ask:
> "If you're showing this to a stakeholder in 6 months, what number do you want to be able to point to?"

## 4. MVP Success Criteria (the go/no-go gate)

This is the most important metric section. It answers:
> "What signal would tell us the MVP worked and we should invest in v2 — versus pivot or kill?"

Examples:
- "100 weekly active users from the target persona within 8 weeks of launch"
- "At least 30% of trial users still active in week 4"
- "5 paying customers willing to renew at $X/month"

The MVP gate should be:
- **Concrete** — a specific number, not "feels good"
- **Time-boxed** — by when?
- **Decision-driving** — if hit → invest; if missed → reconsider

## 5. Reflect & Confirm

```
Here are the metrics:

**User Success:**
| Metric | Target | How to Measure |
| ... | ... | ... |

**Business Objectives:**

| ... | ... | ... |

{1-2 sentences}

Does this give us a clear picture of "is this working"?
```

Iterate until confirmed.
